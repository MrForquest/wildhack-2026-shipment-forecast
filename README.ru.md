# Отгрузки без простоев - решение (соло-трек)

*[English version](README.md)*

Решение для хакатона [WB Wildhack 2026: «Отгрузки без простоев»](https://wbspace.wb.ru/competitions/otgruzki-bez-prostoev).

## Задача

Нужно спрогнозировать объём отгрузок (`target_1h`) по маршрутам (`route_id`) на 4 часа вперёд по историческим временным рядам: таргету и шести служебным статусам (`status_1`...`status_6`). Ряды дискретны с шагом 30 минут (48 точек в сутках).

**Метрика:** `WAPE + |Relative Bias|`

```
WAPE = Σ|y_pred - y_true| / Σ|y_true|
RBias = |Σy_pred / Σy_true - 1|
```

## Данные

- `train_solo_track.parquet` - история по маршрутам: `timestamp`, `route_id`, `status_1..status_6`, `target_1h`.
- `test_solo_track.parquet` - тестовая выборка, для которой нужно предсказать `target_1h`.

Файлы в решении подгружаются из Google Drive, ноутбук рассчитан на запуск в Google Colab.
Сами данные не выкладываются согласно правилам хакатона.


## Опробованные подходы

Самым первым был запущен CatBoost с лагами, но одних лагов было явно мало. Тогда начал пробовать разные агрегации (скользящие средние и std, статистики по часам/дню недели, "скорость" изменения статусов) - это дало малый прирост и снова плато около 0.355 метрики на лидерборде.

Дальше начал пробовать разные модели из `darts`. Пробовал трансформеры, но они обучались слишком долго, а на валидации показывали результат хуже CatBoost.

Но потом я нашёл **TiDE (Time-series Dense Encoder)** - архитектуру на полносвязных слоях, которая обучается очень быстро и при этом работает не хуже трансформеров. С ней получил прирост метрики и до конца хакатона подбирал гиперпараметры (глубину энкодера/декодера, hidden size, длину истории, лосс).

Как итог она использует:
- `status_1...status_6` как past covariates;
- циклические признаки `hour` и `dayofweek` как future covariates;
- относительную позицию во времени (past/future encoders от `darts`);
- масштабирование входа и целевой переменной через `Scaler`.

Помимо этого делал коррекцию bias: считал на валидации коэффициент `bias_coef = Σy_true / Σy_pred` и умножал на него финальные предсказания - это отдельно подтягивало Relative Bias к нулю без переобучения модели (использовалось и для CatBoost, и для TiDE).

## Результат

Лучший результат на локальной валидации показала модель **Darts TiDE** с honest backtest (горизонт 8 шагов, stride 8):

```
WAPE + Bias ≈ 0.329
```
